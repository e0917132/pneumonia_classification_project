# 데일리 로그: Mission 2 (개선 전략 설계)

**[오늘 목표]**
* 적용할 개선 전략을 2가지 이상 선정하고, 각 전략의 선택 이유를 작성한다.

**[선택한 방법]**
* 전략 1. 데이터 전처리
  * letterbox (비율 유지 + 검은 패딩, 224×224)
  * 검은 여백 크롭 (임계값 기반 바운딩 박스, 임계값은 train에서만 결정)
  * 데이터 증강 (회전 ±10° 이내, 미세한 이동·확대, 가벼운 밝기·대비 변화, 좌우 반전 제외)
* 전략 2. 모델 변경
  * ResNet18 (ImageNet 사전학습)
  * DenseNet121 (ImageNet 사전학습)
  * 앙상블 (두 모델의 확률 평균, 가중치와 임계값은 OOF 기준으로 결정)
* 공통 학습 설정: 클래스 가중치, label smoothing 0.05, AdamW + Cosine LR

**[선택 이유]**
* **letterbox**: baseline의 강제 Resize는 흉곽 비율을 왜곡한다. train은 이미 letterbox 형태이고 test는 원본 비율이므로, 같은 방식으로 맞춰야 입력 분포가 일치한다.
* **여백 크롭**: train의 내용 비율(0.663)이 낮아서 흉곽이 프레임을 충분히 채우지 못한다. test와 프레이밍이 달라서 train의 여백을 먼저 제거한다. 임계값을 test로 정하지 않는다는 원칙을 지킨다.
* **증강**: 5,216장은 적은 편이라 과적합 위험이 있다. 범위를 작게 잡는 이유는 흉부 X-ray의 해부학적 구조가 과한 변형으로 왜곡되기 때문이다. 좌우 반전은 심장 위치와 'R' 마커가 뒤집혀서 제외한다.
* **ResNet18**: 가볍고 빨라서 반복 실험에 적합하다. 사전학습 전이학습의 표준적인 출발점이므로 비교 기준으로 쓴다.
* **DenseNet121**: 각 층이 앞선 특징을 재사용하는 구조라서 작은 데이터에 유리하다고 알려져 있다. ResNet과 연결 방식이 달라서 다른 오류 패턴을 보일 가능성이 있고, 이것이 앙상블에서 장점이 된다.
* **앙상블**: 서로 다른 구조의 오류를 평균하면 개별 오류가 줄 수 있다. 추가 학습 없이 기존 결과를 조합하므로 비용이 작다.
* 제외한 전략: 해상도 확대(train 원본이 224라 새 정보가 없음), 배치와 epoch 튜닝(현재 메모리 문제 없고 고정 epoch에서 수렴), ViT(데이터가 적어 사전학습 없이는 불리), EfficientNet과 ConvNeXt(실험 시간 고려해 우선순위 낮춤).

**[결과]**

| 전략 | 개선 영역 | 기대 효과 | 검증 방법 |
|---|---|---|---|
| letterbox | 데이터 | train과 test의 입력 형태 일치 | 같은 fold의 검증 점수와 test 예측 분포 비교 |
| 여백 크롭 | 데이터 | 프레이밍 차이 감소 | 크롭 전후 내용 비율과 종횡비 비교, 검증과 리더보드 확인 |
| 증강 | 데이터 | 과적합 감소, 일반화 향상 | 증강 강도별 OOF 비교 |
| ResNet18 | 모델 | 빠른 반복 실험과 기준 제공 | 5-fold OOF 점수 |
| DenseNet121 | 모델 | 다른 오류 패턴 확보 | 같은 조건에서 fold 0 먼저 비교, 이후 5-fold |
| 앙상블 | 모델 | 개별 오류 감소 | 가중치와 임계값을 OOF로 결정 |

* 이 단계는 계획 단계라서 성능 결과는 없다. 실제 결과는 Mission 3에 기록한다.

**[달성도]**
* 전략 2가지 이상 선정: **성공** (데이터 전처리 3개, 모델 변경 3개)
* 각 전략의 선택 이유 작성: **성공** (문제, 성능 영향 근거, 제외한 대안, 개선 영역 포함)
* 목표 성능(리더보드 0.98)에 대한 직접 달성도는 이 단계에서 판단하지 않는다.

**[인사이트]**
* 검증 데이터가 train과 같은 분포라서, 입력 형태를 맞추는 전략은 검증 점수에서 효과가 드러나지 않을 수 있다. 효과는 test 쪽에서 확인해야 하므로 검증 점수만 보고 판단하면 안 된다.
* 임계값, 가중치, 전처리 파라미터는 train이나 OOF에서만 정해야 한다. test 결과로 고르면 누수가 된다.
